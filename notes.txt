Taskmarket live market visualizer — deliverable notes
Bounty: TSK-BRK611AN ("Build and host Taskmarket's live market visualizer")

Live URL: https://luyquan.github.io/taskmarket-pulse/
Repo URL: https://github.com/LuYquan/taskmarket-pulse

Stack: static HTML + vanilla JS (no framework, no build step, no tracking) +
  generated data.json. Inline SVG charts. Brand fonts/mark hotlinked from
  Taskmarket's official brand kit gist.

Endpoints used (https://api.taskmarket.dev, public, no key):
  - /api/market/stats?chainId={8453,4217}
  - /api/stats/breakdowns?chainId={8453,4217}
  - /api/stats/platform-time-series?chainId=8453&range=7d|30d|90d|all&bucket=day|week
  - /api/stats/activity-heatmap?chainId=8453&range=30d&dimension=hourOfWeek|mode
  - /api/stats/activity-feed?chainId={8453,4217}&limit=50
  - /api/tasks?chainId={8453,4217}&status={open,completed,cancelled,expired,claimed,
    pending_approval,worker_selected}&sort=newest&limit=100 (fully paginated)

Refresh method/frequency: server-side fetch in GitHub Actions, hourly
  (.github/workflows/refresh.yml runs scripts/fetch.py, commits data.json if
  changed, and redeploys to Pages). The page itself makes no API calls.
  Data cached >= 60s; visible "Data as of" time (UTC) in the header and footer.

Deploy command (one command):
  git push origin main
  (GitHub Actions deploys to Pages automatically; no secrets or server needed.
  Pages source must be "GitHub Actions" in the repo settings.)
